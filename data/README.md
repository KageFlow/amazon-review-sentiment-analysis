# Dataset instructions

`amazon_reviews_demo.csv` contains synthetic example review sentences created for testing the notebook. It is not scraped from Amazon and does not represent real customer opinions.

For the final project, replace or supplement it with a real review dataset that you are permitted to use. Record:
- Dataset title and source URL
- License or usage terms
- Download date
- Any filtering or relabelling performed

Required CSV columns:
- `review`: text of the product review
- `sentiment`: `positive` or `negative`

Keep the two sentiment labels consistent and check class balance before training.
